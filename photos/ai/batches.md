# ScrollWise image batches

All 116 pictures from `prompts.csv`, split into **23 batches** of 3–8 images, ready to paste into an image generator one batch at a time.

Batches are grouped by creator. Creators and pets who appear in several photos come first, with their **profile picture first**, so you can keep using it as the reference for the rest of their batch. Carousel photos (`-2`, `-3`) are always in the same batch as their main photo, so they look like the same moment.

**How to work through it**

1. Copy one batch (the grey box plus its prompts) into your image generator.
2. Save each image under the file name shown, e.g. `post-mirror-fit.jpg`. `.png` is fine too.
3. When you have a few batches done, put the images in a ZIP and send it to Claude with a message like:
   > Here are the ScrollWise images for batches 1–4. Please install them.
4. Claude installs them, checks each one against its scene, updates `missing.csv` and republishes. You can send ZIPs in as many rounds as you like.

If a picture comes out wrong (extra fingers, odd faces, visible text or logos, the wrong scene), just generate it again before saving.
