# Research materials

| File | What it is |
| --- | --- |
| `ScrollWise-Research-Guide.pdf` | The printable guide for the student team: research question, hypothesis, variables, recruitment, consent and privacy, step-by-step procedure, counterbalancing, data export, data dictionary, analysis, suggested charts, honest interpretation, limitations, plus the appendix sheets. |
| `ScrollWise-Results-Template.pdf` | The appendix on its own, ready to print: order list (P001–P060), blank recording sheet, blank results tables and checklists. |
| `sample-structure.csv` | An empty CSV with the exact columns that research mode exports. It contains no participant data. |
| `source/research-guide.html` | The source of the guide. To change it, edit this file, open it in Chrome, then File → Print → Save as PDF (paper A4, “Background graphics” ticked). |

No participant data is stored in this folder or anywhere else in the project. Research results only exist in the browser where they were recorded, until the team exports them. Keep exported files in a school account, never in this repository.
